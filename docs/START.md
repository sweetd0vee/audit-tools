## Ежедневное правило за клавиатурой

Перед новым файлом:

1. Это `.tsx` / новый экран? Стоп.
2. Это уже умеет Open WebUI настройкой? Стоп, пишем в `seed/`.
3. Это вызов существующего API из чата? Tool в `seed/openwebui/tools/`.
4. Это HITL, allowlist, кейс, trail, нарезка статьи? `backend/app/`.
