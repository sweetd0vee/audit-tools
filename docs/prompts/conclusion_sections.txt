Правила нумерации:
- Наблюдения нумеруй как 3.M, где M — порядковый номер 1…{hypothesis_count}.
- Поле «гипотеза:» — номер из списка подтверждённых гипотез, каждый номер ровно один раз.
- Поле «программа:» — номера пунктов программы, которые закрывает это наблюдение.
- «существенность:» только одно из: высокий / средний / низкий.
- Таблицы пиши markdown `| … |`. Схемы — подписью «Схема:» и списком/цепочкой шагов.
- Не пиши «Конец документа» и блоки подписи.
