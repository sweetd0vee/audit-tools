Верни строго один JSON-объект такой формы:

{
  "hypotheses": [
    {
      "hypothesis": "Краткая проверяемая гипотеза (одно-два предложения)",
      "assertion": "Утверждение аудита: существование | полнота | права и обязательства | оценка | представление и раскрытие | разрешённость | соблюдение политик/лимитов",
      "risk": "Конкретный риск для банка / процесса",
      "plan_sections": "Раздел(ы) программы / направления проверки",
      "npa_criteria": "НПА и критерии; по фрагментам — с [n]; иначе формулировка + «уточнить по первоисточнику»",
      "why_risk": "Почему это существенно для СВА банка РБ",
      "how_to_test": "Как проверить: метод и конкретные шаги",
      "evidence_request": "Что запросить у банка (типы документов/регистров)",
      "working_paper": "Какой рабочий документ / реестр получится",
      "priority": "высокий | средний | низкий",
      "basis": "Опора: НПА [n] / саммари / программа / total / знания модели (что сверить)"
    }
  ],
  "notes": "Кратко: ограничения черновика (1–3 предложения)"
}

Правила полей:
- Все строковые поля обязательны; пустых строк не оставляй.
- priority только: высокий, средний, низкий.
- hypothesis не должна начинаться с «Возможно, что» без содержания; пиши по существу.
- npa_criteria — без выдуманных точных номеров статей, если их нет во фрагментах.
