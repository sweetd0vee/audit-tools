## Название проверки
Повтори название проверки из задания. Одним абзацем: что проверялось, за какой период, на какую службу/процесс банка РБ это ориентировано (без выдуманных реквизитов приказа).

## Цели и задачи аудита
Сначала строка «Цели аудита:», затем 3–6 маркированных пунктов. Цели и задачи выведи из названия проверки, программы (если есть) и подтверждённых гипотез: оценка процесса / СВК / рисков по теме, выработка рекомендаций. Без воды.

## Инструменты проверки
1–2 абзаца связным текстом (не таблица). Какие приёмы и материалы использовались: анализ ЛПА и НПА РБ, программа проверки, чеклист гипотез, сверка / запрос документов / сопоставление с критерием — только то, что следует из материалов кейса и полей «как проверить» подтверждённых гипотез. Не перечисляй софт вроде Qlik, если его нет в материалах.

## Аудиторское мнение
Главный раздел, 1,5–3 страницы повествования.
Структура внутри раздела (подзаголовки ### не обязательны; можно абзацами и короткими маркированными списками):
- ввод: по совокупности рассмотренных вопросов и подтверждённых гипотез — агрегированный взгляд;
- что исследовано (кратко по каждой подтверждённой гипотезе, не копируя формулировку один в один);
- позитивные наблюдения — только если они явно следуют из материалов; иначе не выдумывай «процесс достаточно эффективен»;
- недостатки и риски — только из подтверждённых гипотез;
- резюме: что это значит для руководства банка.

Не таблица. Не нумеруй гипотезы как в Excel, если это ломает повествование; допустимы короткие списки факторов.

## Рекомендации
Краткое резюме рекомендаций по подтверждённым гипотезам: что предложить объекту аудита. Маркированный список 3–8 пунктов, каждый — одно-два предложения. Группируй по смыслу (контроль, учёт, ЛПА, комплаенс), не по номеру гипотезы. В конце один абзац: детализация — в последующих разделах заключения / рабочих документах; это черновик раздела I.

Правила оформления:
- Только подтверждённые гипотезы.
- Абзацы 3–6 предложений, официально, без канцелярита «необходимо отметить тот факт, что».
- Маркированные списки — минусом `- `, нумерация целей — тоже `- `.
- Не пиши ## Источники и не ставь [n], если это не помогает руководству; нормы можно назвать словами.
- Не добавляй глоссарий аббревиатур.
- Не пиши «Конец документа» и блоки подписи.
