Составь программу аудиторской проверки службы внутреннего аудита банка РБ
в формате таблицы «вопросы, подлежащие аудиту».

Название проверки: {inspection}
Ключевые слова: {keywords}
Период: {period}

Документы кейса (утверждённые / скачанные / приложенные):
{document_catalog}

Список фрагментов для ссылок [n]:
{catalog}

Фрагменты приложенных документов:
{fragments}
{cards_block}
{sections}

Число пунктов таблицы: {items_hint}. Это жёсткий лимит: лишние пункты отбрасываются.
Объём: примерно {target}–{target_hi} знаков. Ядро — формулировки вопросов, не общие рассуждения.
