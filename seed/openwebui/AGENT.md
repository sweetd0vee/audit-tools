# Первый агент

Агент — не «ещё одна модель». Это **цикл с руками и стоп-краном**.

```
сообщение аудитора
  → понять фазу (код, не свободный ReAct)
  → вызвать API кейса (руки)
  → если нужен человек — остановиться
  → иначе следующий tool
  → ответ + цитата
```

Локальный Qwen 35B плохо держит native tool-calling. Поэтому **главный агент — Pipe**: фаза и HITL в Python. Модель предлагает список НПА и отвечает по фрагментам, но не решает «качать или нет».

```
Аудитор  →  Pipe «Аудитор»  →  Audit Tool Server  →  Ollama / SearXNG / диск
                 ↑ HITL: download только после «утверждаю»
```

Не пишем LangGraph, мультиагентов и свой чат.

---

## Что поставить (5 минут)

1. `docker compose up -d --build` — Open WebUI :3000, backend :8100.
2. Open WebUI → **Workspace → Functions → +**
3. Вставьте целиком [`functions/audit_agent.py`](functions/audit_agent.py)
4. Включите функцию (toggle). Valves: `AUDIT_API=http://backend:8100`  
   Если WebUI не в Docker — `http://localhost:8100`.
5. Новый чат → в списке моделей **Аудитор**.

Не путать с Workspace → Models → «Аудитор» на базе Ollama. Pipe сам появляется как модель.

### Сценарий

```
Проверка аренды коммерческой недвижимости, 2025, аренда, валюта, НДС
```

Агент создаёт кейс, предлагает список, **ждёт**. Затем:

```
утверждаю 1, 2, 4
```

Качает, синкает Knowledge. Потом вопрос по пункту акта — ответ с цитатой.

«Все обязательные» = только `priority=1`. Ссылка: `к 3 url https://pravo.by/...`

## Запасной путь: Tools + Ollama

[`tools/audit_case.py`](tools/audit_case.py) — руки без цикла. Workspace → Tools → вставить → привязать к чат-модели → Function calling **Native**.

35B часто вызовет `download` без утверждения или не вызовет tool вовсе. Для обучения полезно, для продукта — Pipe.

Промпт для этой связки: [`SYSTEM_AUDITOR.txt`](../SYSTEM_AUDITOR.txt).

## Почему это уже агент, а не скрипт

| Часть | Где |
|---|---|
| Память проверки | `case_id` в чате (`<!--audit-case:...-->`) + файлы сервера |
| Руки | HTTP на уже существующие эндпоинты |
| Мозг | Ollama: propose и ask на сервере; Pipe не дублирует RAG |
| Стоп-кран | нет select — сервер не качает; Pipe не идёт дальше списка |
| Наблюдаемость | статусы в UI («Создаю кейс…», «Качаю…») |

Круче станет не от второго агента, а когда цитата стабильна и 35B не нужна для выбора фазы. Следующий шаг после этого файла — золотые вопросы RAG, не «оркестратор».
